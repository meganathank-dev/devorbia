# Third-party components

This archive contains original DevOrbia source and the user's supplied specifications. It does not bundle npm dependency code, MongoDB binaries, Node binaries or downloaded fonts/images.

Runtime and development dependencies are declared in the three package manifests. They include React, React Router, Zustand, Axios, Lucide, Recharts, Tailwind CSS, Vite, Express, Mongoose, Zod, Helmet, CORS middleware, express-rate-limit, cookie-parser, compression, Nodemailer, dotenv, ESLint, Prettier and Supertest.

Each component retains its own license and notices. Review installed package license files after resolving dependencies. Node.js and MongoDB Community are separately installed runtime/database products with their own licenses; the original-code MIT notice does not relicense either product or its dependencies. MongoDB Community's licensing is separate from the availability of a zero-subscription local installation.

No paid AI SDK, hosted inference service, proprietary UI kit or commercial asset license is required by the implementation. Optional SMTP or hosted infrastructure is configured by the operator under the selected service's own terms.
